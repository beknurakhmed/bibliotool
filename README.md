# bibliotool — библиометрический анализ с семантическим слоем

Инструмент для проектной работы «Bibliometric Analysis as a Method of Scientific Research»
(Scientific Research Methodology, Bucheon University in Tashkent). Автор: Ахмедов Бекнур.

Работает на открытой базе **OpenAlex** (без подписки), выполняет классический библиометрический
анализ и дополняет его **семантическим слоем**: группирует публикации по смыслу аннотаций,
а не по совпадению ключевых слов, и подписывает кластеры языковой моделью.

## Что делает

| Этап | Что считается | Как |
|---|---|---|
| Статистика | публикации по годам, страны, организации, источники, языки, типы, OA | `group_by` по **всему** массиву (1 запрос = точные счётчики по 100k+ работ) |
| Выборка | 2000 записей с аннотациями и списками литературы | `sample` (случайная, seed) или `recent` (по дате). Релевантность намеренно исключена |
| Сети | соавторство, коцитирование, библиографическое сопряжение | networkx → GEXF (Gephi), CSV, map/network (VOSviewer) |
| Семантика | эмбеддинги → кластеры → ключевые слова (c-TF-IDF) → описание LLM → слабо представленные направления | sentence-transformers (мультиязычная модель), UMAP + HDBSCAN (fallback KMeans), Ollama или Claude |
| Методы | тип исследования, базы данных, инструменты в аннотациях | эвристика по ключевым фразам (ограничение: работает нестабильно) |
| Отчёт | Markdown + PNG-графики; интерактивный UI | matplotlib, Streamlit + Plotly |

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env          # вписать OPENALEX_API_KEY
```

Ключ OpenAlex бесплатный: https://openalex.org/settings/api. Бюджет $1/день;
прогон на 2000 записей стоит ≈ $0.04 (поисковый запрос — 10 кредитов, `group_by` — 1 кредит).

LLM для описания кластеров — по умолчанию локальная **Ollama** (`qwen2.5:7b`), полностью
офлайн. Альтернатива: `LLM_PROVIDER=anthropic` + `ANTHROPIC_API_KEY` (модель `claude-opus-5`).

## Использование

```bash
# полный прогон: статистика + выборка + сети + семантика + отчёт
python -m bibliotool run "bibliometric analysis" --from 2015 --to 2026 --mode sample --limit 2000 --semantic --llm

# только семантика для уже сохранённого прогона / пересобрать отчёт
python -m bibliotool semantic runs/bibliometric_analysis_2015_2026_sample --llm
python -m bibliotool report   runs/bibliometric_analysis_2015_2026_sample

# интерфейс
streamlit run app/streamlit_app.py
```

Результаты прогона — в `runs/<запрос>_<годы>_<режим>/`:

```
meta.json, stats.json      параметры и полная статистика (group_by)
works.csv                  выборка: метаданные + аннотации
references.json            списки цитируемых работ (для сетей)
networks/*.gexf            сети для Gephi
networks/*_vos_*.txt       сети для VOSviewer (File → Open → map + network)
semantic.json              кластеры, описания, слабо представленные направления, методы
semantic_docs.csv          кластер и 2D-координаты каждой работы
report.md + *.png          отчёт
```

Ответы API кешируются в `.cache/` — повторный прогон с теми же параметрами не тратит кредиты.

## Структура

```
bibliotool/
  openalex.py   клиент: фильтры, group_by, sample/recent, кеш, учёт бюджета
  data.py       восстановление аннотаций из инвертированного индекса, таблицы, хранение
  stats.py      статистика по массиву и по выборке (+ проверка смещения выборки)
  networks.py   соавторство, коцитирование, сопряжение; экспорт Gephi/VOSviewer
  semantic.py   эмбеддинги, кластеризация, c-TF-IDF, описание LLM, методы/инструменты
  llm.py        единый интерфейс Ollama / Anthropic
  report.py     графики и Markdown-отчёт
  cli.py        командная строка
app/streamlit_app.py       UI
tests/                     офлайн-тесты (pytest)
```

## Методологические замечания, встроенные в инструмент

- **Смещение выборки.** Сортировка по релевантности отбирает старые цитируемые работы и
  показывает ложный «спад» публикаций. Инструмент её не использует и предупреждает, если в
  выборке нет работ с нулевой цитируемостью (§5.1 описания проекта).
- **Сети и выборка.** При случайной выборке сеть соавторства распадается: для сетевого анализа
  нужна сплошная выгрузка по узкой теме. Единая процедура сбора не годится для всех видов анализа (§5.4).
- **«Слабо представленные направления»** — это области с малым числом публикаций *в данной базе
  и выборке*, а не пробелы в науке (§6.2).
- **Языковой охват.** Неанглоязычная наука, включая узбекскую, в OpenAlex представлена
  непропорционально мало — анализ не отражает национальную научную продукцию (§5.5).
